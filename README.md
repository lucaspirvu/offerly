# Offerly

Mini-aplicație Expo/React Native pentru cupoane și alerte de preț, cu conținut demonstrativ verificabil.

## Dezvoltare locală

1. Instalează Node.js 20+
2. Rulează `npm install`
3. Pornește aplicația cu `npm start`
4. Scanează codul QR cu **Expo Go** (Android/iOS)

## Stack

- Expo
- React Native
- TypeScript

## Notă

Aplicația nu generează sau falsifică reduceri. Produsele și cupoanele demonstrative trebuie înlocuite cu oferte reale primite de la magazine sau prin API-uri oficiale.
